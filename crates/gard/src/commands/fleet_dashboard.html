How this fleet works

  1. gard scan audits each machine and signs the report (Ed25519).
  2. gard fleet submit sends it here; the server verifies the signature and the team roster before accepting.
  3. This page recomputes from the latest verified reports every 30 seconds.
  4. Before a ceremony: gard attest + co-signers run gard verify.
